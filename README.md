# Dark-Pattern-Detector-for-E-Commerce-Websites
NLP-based screening of e-commerce text for potential dark patterns. Compares TF-IDF classifiers, Word2Vec + BiLSTM and fine-tuned DistilBERT, with validation-based model selection, explainability and error analysis. DistilBERT achieved 88.1% test accuracy and 0.729 F1 for the dark-pattern class.
